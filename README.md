# 青山整形外科クリニック 公式サイト（静的HTML/CSS）

大分県別府市の「医療法人 青山整形外科クリニック」公式サイトです。ビルド不要の静的HTML/CSSで構成されています。

## 構成

```
/index.html          ホーム
/about.html           クリニック紹介（医院全景・院内紹介・医院概要）
/doctor.html          院長・スタッフ紹介／整形外科専門医について
/medical.html         診療案内（診療科目・リハビリテーション・スポーツリハビリ・障害予防）
/hours.html           診療時間・休診案内
/access.html          アクセス・駐車場
/news.html            お知らせ
/faq.html             よくある質問
/recruit.html         採用情報
/downloads.html       各種書類ダウンロード
/links.html           関連リンク
/column.html          院長・スタッフだより
/sitemap.html         サイトマップ
/privacy.html         プライバシーポリシー
/terms.html           利用規約
/robots.txt
/assets/css/style.css
/assets/images/       写真・図版
/assets/downloads/    ダウンロード資料（PDF/DOC）
```

## デプロイ

ビルド不要の静的ファイルのため、GitHub Pages・Netlify・Cloudflare Pages等、静的ホスティングであればそのまま公開できます。

## 内容の出典について

本サイトの住所・電話番号・診療時間・院長/スタッフ情報・プライバシーポリシー・利用規約・写真等は、当院の旧公式サイト（aocli.com）の公開情報をもとに移行・再構成したものです。詳細は [CONTENT-TODO.md](./CONTENT-TODO.md) を参照してください。
